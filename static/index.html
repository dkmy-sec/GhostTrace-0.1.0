LOCAL PAIRING

Connect your browser.

Load the included extension folder in Chrome or Edge, then paste this key into its popup.

  1. Open chrome://extensions or edge://extensions.
  2. Enable Developer mode → Load unpacked.
  3. Select the extracted GhostTrace/extension folder.
  4. Click GhostTrace’s toolbar icon. Paste the key, then Save & connect.

Keep the collector window running. Private windows are excluded. You can exclude individual sites in the extension popup.

 READ THE EVIDENCE

A clearer view of your browsing.

Known tracker

A domain or resource matched DuckDuckGo Tracker Radar. It’s a classification, not proof of everything collected.

Broker affiliation

A domain or exact company name matches the California registry. Registration describes the company’s activities, not a sale from this request.

Fingerprinting association

The tracker dataset has recorded fingerprinting behavior. GhostTrace v1 doesn’t instrument browser APIs to prove it happened here.

Identifier signal

A known advertising identifier parameter appeared. Parameter values are discarded.

Map estimates

The bundled database identifies countries. Markers are arranged near country labels for visibility. Shared hosting, CDNs, proxies and VPNs can complicate location and attribution.

What stays invisible

Server-to-server sharing, historical data purchases, some browser-internal requests, and resources served from memory cache. This version observes the browser, not every Windows process.

Seven-day retention · 100,000-observation cap · View/export cap: 20,000 observations per window. No response bodies, cookie values, URL paths or query values are stored.

 LOCAL RECORDS

Clear your observations?

This deletes the collector’s stored browsing metadata. Pairing and bundled datasets stay available. If the extension has an offline queue, discard it in its popup too.
